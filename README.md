# XR-Viewer
*Student Group Project for the Augmented Reality Course in the Summer Semester of 2025*

## Content
This project was built using **Godot Engine 4.4** for usage with the Meta Quest 3 device in **AR mode**.</br>
The project contains a functional vending machine to interact with. The machine has various objects to offer that can be extracted and played with!

## Functionality
To get an object from the vending machine, with a controller, press one of the white buttons.</br>

**Grabbing object** - side grip button</br>
**Selecting object from afar** - point right controller at object + Button A</br>
**Scaling object** - SELECT object + right controller Analog Stick UP and DOWN</br>

**Rotating Scene** - left controller Analog Stick LEFT and RIGHT</br>

## Setup
### using the APK
The project contains the .apk that can be installed onto the Meta Quest 3 device!
[XR_Viewer.apk](https://github.com/hunsri/xr-viewer/blob/main/XR_Viewer.apk)

### using Godot
This method requires a bit more time.
The project can be deployed and installed to a Meta Quest 3 device using the Godot Engine.</br>
Open the project in the Godot Engine.</br>
It is recommended to use the projects used version [Godot 4.4](https://godotengine.org/download/archive/4.4-stable/).</br>
After that you will need to install [Android Studio](https://developer.android.com/studio).</br>

A good tutorial on how to setup the project and deploy it can be found [here](https://www.youtube.com/watch?v=shbHGhkh4NM) and [here](https://www.youtube.com/watch?v=8B8RnFokAFc)</br>

After everything is set up you can use the Godot Remote Deploy to install the project on the Meta Quest 3 device.
